# 🚀 Kubernetes Manifest YAML Files Project

This repository contains **step-by-step Kubernetes manifest YAML files** covering
**real-world Kubernetes concepts** such as deployments, services, ConfigMaps,
Secrets, StatefulSets, Blue-Green deployment, HPA, and EFK logging.

The project is written in a **simple and structured way** so that beginners
can understand Kubernetes easily.

---

## 📌 Project Objective

👉 Learn and implement **core Kubernetes concepts** using YAML manifests  
👉 Understand **production-level deployment patterns**  
👉 Practice **hands-on Kubernetes configuration**

---

## 🧰 Technologies Used

- Kubernetes
- YAML
- Docker (container images)
- kubectl
- Git & GitHub
